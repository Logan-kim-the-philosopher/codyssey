# B3-1 환경 예외

원문 요구사항은 모든 실습 리소스를 서울(ap-northeast-2)에 생성하는 것이다.
사용자는 새 AWS 경험의 프로젝트 cdsy가 시드니(ap-southeast-2)에 배정된 상태에서 시드니로 과제를 진행하기로 결정했다.
고급 기능 활성화는 수행하지 않았다. 서울 요구사항은 충족으로 표시하지 않는다.

- 프로젝트: cdsy
- CLI 프로필: codyssey
- 프로젝트 계정 식별자: 888782968605
- 실제 리전: ap-southeast-2
- 무료 플랜 사전 확인: ACTIVE / FREE
- 확인 당시 남은 크레딧: USD 100.0
- 요구사항 연결: REQ-001-C01

AWS CLI 기본 리전 변경은 프로젝트의 리전 제한을 제거하지 않는다.

## 완료 기준에 대한 사용자 승인

사용자는 지정 리전 제한을 과제 완료 예외로 수용했다. 서울에서 수행했다는 뜻이 아니라, 시드니에서의 실습과 환경 제약 설명으로 해당 완료 기준을 대체한다. 원문과 원래 기준은 보존한다.
리전 변경 자체가 불가능한 것은 아니다. 고급 기능 활성화는 유료 플랜 전환 및 비가역 변경을 수반하므로, 현재 프로젝트 모드를 유지하는 범위에서는 지정 리전을 바꿀 수 없다.
