# 이전 B3-1 미션 실제 적용 계획

대상 저장소: https://github.com/Logan-kim-the-philosopher/codyssey
대상 미션: B3-1. 실제 원격 PR 작성 전 단계이며 PR 링크·AI 생성 증거는 아직 없다.

의미 있는 변경 후보: B3-1 README에서 최초 배포와 재검증의 주소가 서로 다름을 표로 정리하고, 삭제한 리소스의 접속 주소가 현재 서비스 주소가 아님을 외부 접속 설명 바로 옆에 표시한다. 기존 예외·원본 실행 증거는 보존한다. 현재 B3-2 내부에만 후보 패치를 보관한다.

실행 예정:
1. codex/b3-2-b3-1-evidence-guide 브랜치에서 후보 패치를 적용·검토한다.
2. 프로젝트 루트에서 이 도구의 commit 명령과 pr 명령을 각 1회 실제 호출한다.
3. AI 초안의 사실·링크·미수행 테스트 표현을 수정한다.
4. 사람이 검토한 커밋·PR을 GitHub에 반영하고 링크를 기록한다.
5. AI 초안 → 최종 PR 차이를 무엇을 왜 고쳤는지 5~10줄 작성한다.

필요 조건: 로컬 API Key 환경변수, 유효한 GitHub 인증, 외부 push/PR 작성 요청. 현재 GitHub CLI 인증은 유효하지 않다. 도구 자체에는 원격 반영 기능을 넣지 않는다.
